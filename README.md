# E_Wallet
features:

1.**Secure PIN Authentication** : The user can type a secret 4-digit PIN before accessing their wallet features. The system will match the inputs against a saved memory value. If the PIN is incorrect for 3 consecutive times, the system will temporarily freeze the interface and block all inputs for a set time window before letting the user try again.

2.**Dynamic Balance Dashboard** : The user can view their current funds instantly at any time. The system will convert the data into a human-readable format, updating the screen instantly whenever a transaction succeeds.

3.**Money Transfer and Mobile Recharge** : The user can transfer funds to another account by typing a phone number and an amount. The user can buy mobile airtime. The system checks if the wallet has enough money before processing any data, rejecting the transaction instantly if funds are insufficient, or executing the transfer and displaying the final success status. 

4.**Micro-Loan** : The user can request an instant cash loan to add to their wallet. The system will process the requested amount, calculate an interest debt, update the total funds, and display the final breakdown of the loan and payback amount.

5.**Transaction History Log** : The user can look back at a statement of their recent activity. The system will record the few latest transactions with specific labels and show them in a dedicated window 

6.**USSD Interactive Menu Dashboard** : The user can navigate options using a mobile banking menu format. The system will clear the console screen and draw a text window layout that updates instantly after every selection.
